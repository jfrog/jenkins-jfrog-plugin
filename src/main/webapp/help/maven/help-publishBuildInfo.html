When checked (the default), build info is captured and published to Artifactory - requiring a JFrog Artifactory Server above. Independent of Deploy Artifacts under Deployment - check either, both, or neither.

All the fields below (JFrog Project, Build Name, Build Number, environment variable capture, Git info capture) only take effect while this is checked; unchecking it hides them since none of them do anything without a build info to attach to.

Both this and Deploy Artifacts only take effect when the project's effective Maven Goals include install or deploy - other goals (for example clean package) skip both.
