When checked, artifacts produced by the Maven build are deployed to Artifactory. Build info is published whenever this Build Settings action is enabled, even if deploy is unchecked, but only when the project's effective Maven Goals include install or deploy. Other goals (for example clean package) skip both deploy and build-info.

Note: leaving Goals and options blank does not skip deploy/build-info — Jenkins' Maven Integration defaults an empty Goals field to install, which counts as an included goal.
