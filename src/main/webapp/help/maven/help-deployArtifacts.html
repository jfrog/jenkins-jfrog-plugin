When checked, artifacts produced by the Maven build are deployed to Artifactory. Independent of Capture and publish build info (under Build info) - check either, both, or neither. Both require a JFrog Artifactory Server above, and only take effect when the project's effective Maven Goals include install or deploy. Other goals (for example clean package) skip both. Leaving JFrog Artifactory Server empty and both checkboxes unchecked is a valid resolution-only setup.

Note: leaving Goals and options blank does not skip deploy/build-info — Jenkins' Maven Integration defaults an empty Goals field to install, which counts as an included goal.
