Optional. The key of a JFrog Platform Project (multi-tenancy / RBAC grouping) to associate this build and its deployed artifacts with — the same concept as the --project flag on jf CLI commands.

If your organization uses JFrog Projects, leaving this empty means the build and its artifacts fall under the default, unassigned scope, and may not be visible to users whose access is scoped to a specific project. Set it to match the project this build's output belongs to.
