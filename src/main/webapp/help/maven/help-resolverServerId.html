Optional. Pick a different JFrog Platform Server (configured under Manage Jenkins → System) to resolve dependencies from than the one used to deploy artifacts and publish build info.

Because credentials in this plugin are tied to the server they're configured on, selecting a different server here also means dependency resolution authenticates with that server's own credentials — completely independent from the deployer's credentials.

Leave empty to resolve dependencies using the same server and credentials as JFrog Platform Server above. Only takes effect when Resolve Repository is also set.
