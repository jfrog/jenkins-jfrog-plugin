Target Artifactory repository to deploy release artifacts to, and to publish build info to, for this Maven Project job (for example, libs-release-local). Used for snapshot artifacts too, unless a separate Snapshot Repository is set below. This field only controls deployment; it has no effect on where dependencies are downloaded from. To also resolve dependencies through Artifactory, set the separate Resolve Repository field below. Otherwise, dependency resolution is left entirely to Maven's own settings.xml (mirrors, profiles, Central, etc.).
