When checked, the Git commit revision, repository URL, and branch (read from the GIT_COMMIT, GIT_URL, and GIT_BRANCH environment variables the Git plugin sets for this build) are recorded in the published build info's structured VCS section - the same section Artifactory's UI reads for a build's "VCS" tab.

This is independent of Capture environment variables above, which sweeps arbitrary environment variables into build info generically rather than populating this dedicated VCS section.
