Optional. Comma-separated Ant-style wildcard patterns (for example *-tests.jar,*-javadoc.jar) matched against each artifact's file name. Matching artifacts are skipped during deployment. Applied after Artifact include patterns — an artifact must pass the include check first, then survive the exclude check.

By default, an excluded artifact can still appear in the published build info (its checksums are recorded even though it wasn't uploaded). Check Filter excluded artifacts from build info below to leave it out of build info entirely too.
