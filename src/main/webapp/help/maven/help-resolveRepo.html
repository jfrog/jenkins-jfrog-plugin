Optional. Artifactory repository (typically a virtual repository, for example maven-virtual) to resolve release dependencies from during this Maven Project build. Used for snapshot dependencies too, unless a separate Resolve Snapshot Repository is set below. Uses the same JFrog Platform Server and credentials configured above, unless a different Resolver Server is set below. Otherwise completely independent of the Artifactory Repository / Snapshot Repository fields, which only control where artifacts are deployed.

Leave this empty to make no change to dependency resolution — Maven will resolve dependencies the way it always does, based on its own settings.xml (mirrors, profiles, Central, etc.), regardless of whether this reporter is enabled.
