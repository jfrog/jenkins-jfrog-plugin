Artifactory repository (typically a virtual repository, for example maven-virtual) to resolve release dependencies from during this Maven Project build. Used for snapshot dependencies too, unless a separate Resolve Snapshot Repository is set below. Uses the server and credentials configured under JFrog Resolve Server above, with no fallback to JFrog Artifactory Server under Deployment. Leave empty to skip dependency resolution. The two are entirely independent of the Release Repository / Snapshot Repository fields under Deployment, which only control where artifacts are deployed.
