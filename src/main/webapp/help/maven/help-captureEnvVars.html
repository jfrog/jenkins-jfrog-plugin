When checked, environment variables from this build are attached to the published build info, useful for traceability (e.g. seeing which CI parameters produced a given artifact).

Which variables are captured is controlled by the Include patterns and Exclude patterns fields below: a variable is included if its name matches an include pattern and does not match any exclude pattern. Exclude patterns are checked after include patterns, so they always win.

Security note: environment variables can contain secrets (tokens, passwords) injected by other build steps or credentials bindings. Leaving Exclude patterns empty applies a built-in safe default that filters out common secret-like variable names, but review your own variable names before relying on it, especially in a shared or regulated environment.
