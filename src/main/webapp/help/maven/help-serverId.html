Select the JFrog Artifactory Server (a JFrog Platform instance) configured under Manage Jenkins → System → JFrog Platform. The same servers are used by Pipeline and Freestyle jobs. This action appears under the Maven Project Build Settings section, not Post-build Actions.

Required whenever Deploy Artifacts or Capture and publish build info is checked - leave both unchecked (and this field empty) for a resolution-only setup using JFrog Resolve Server / Resolve Repository instead.
